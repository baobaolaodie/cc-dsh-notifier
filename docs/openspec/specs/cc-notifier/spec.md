## Purpose

在 Claude Code 需要用户介入且用户未聚焦于会话窗口时,通过桌面通知弹窗及时提醒用户,包含事件上下文与项目信息,并支持点击跳回会话窗口。

## ADDED Requirements

### Requirement: 中断事件触发通知
系统 SHALL 在以下 Claude Code 中断事件发生时评估并触发通知:Claude 请求工具执行权限、Claude 通过 AskUserQuestion 向用户提问、Claude 完成本轮输出停下等待用户输入、工具执行失败。

#### Scenario: 权限请求触发通知
- **WHEN** Claude 请求执行工具(如运行命令)需要用户批准
- **THEN** 系统评估是否通知用户(受聚焦状态约束)

#### Scenario: 提问触发通知
- **WHEN** Claude 调用 AskUserQuestion 向用户提问
- **THEN** 系统评估是否通知用户(受聚焦状态约束)

#### Scenario: 输出完成触发通知
- **WHEN** Claude 完成本轮输出并停下等待用户下一条指令
- **THEN** 系统评估是否通知用户(受聚焦状态约束)

#### Scenario: 工具执行失败触发通知
- **WHEN** Claude 执行的工具调用返回失败结果
- **THEN** 系统评估是否通知用户(受聚焦状态约束)

### Requirement: 聚焦感知
系统 SHALL 在通知前检测目标会话所在窗口的聚焦状态;窗口处于聚焦状态时系统 SHALL 不发出通知;窗口失焦时系统 SHALL 发出通知。

#### Scenario: 会话窗口聚焦时不通知
- **WHEN** 目标会话所在窗口处于前台聚焦状态且发生中断事件
- **THEN** 系统不发出任何通知

#### Scenario: 会话窗口失焦时通知
- **WHEN** 目标会话所在窗口未处于前台聚焦状态且发生中断事件
- **THEN** 系统发出通知

### Requirement: 桌面弹窗通知与声音
系统 SHALL 使用自绘桌面弹窗(屏幕右下角,自动消失)展示通知,并在展示时附带声音提醒。

#### Scenario: 展示弹窗并播放声音
- **WHEN** 系统发出通知
- **THEN** 屏幕右下角展示通知弹窗,并播放系统提示音

### Requirement: 通知内容
通知 SHALL 包含事件类型与项目名;在事件提供上下文信息时,通知 SHALL 附带上下文摘要(权限请求的工具与命令、提问内容预览、工具失败的错误信息)。

#### Scenario: 权限请求通知包含命令与项目名
- **WHEN** 权限请求事件触发通知
- **THEN** Toast 正文显示请求执行的命令摘要与所在项目名

#### Scenario: 提问通知包含问题预览
- **WHEN** AskUserQuestion 事件触发通知
- **THEN** Toast 正文显示提问内容预览与所在项目名

#### Scenario: 失败通知包含错误信息
- **WHEN** 工具执行失败事件触发通知
- **THEN** Toast 正文显示失败摘要与所在项目名

### Requirement: 点击跳转
用户点击通知弹窗时,系统 SHALL 将对应会话所在窗口激活并置于前台。

#### Scenario: 点击弹窗激活会话窗口
- **WHEN** 用户点击已展示的通知弹窗
- **THEN** 对应会话所在窗口被激活并置于前台

### Requirement: 通知历史记录
系统 SHALL 将每次发出的通知(时间、项目名、事件类型、摘要)追加到本地历史记录文件,供用户回溯已错过的通知。

#### Scenario: 通知写入历史记录
- **WHEN** 系统发出通知
- **THEN** 通知内容(时间、项目、事件、摘要)追加到历史记录文件

### Requirement: 配置覆盖
系统 SHALL 默认全局生效;单个项目 SHALL 能够通过项目级配置覆盖全局配置,包括完全关闭通知。

#### Scenario: 项目级关闭通知
- **WHEN** 项目级配置将通知关闭,且该项目内发生中断事件
- **THEN** 系统不发出任何通知

#### Scenario: 全局默认生效
- **WHEN** 未配置项目级覆盖的会话内发生中断事件
- **THEN** 系统按全局配置发出通知

### Requirement: 通知服务生命周期
系统 SHALL 在 Claude Code 会话启动时自动启动通知服务,并在全部会话结束时自动停止通知服务;无需用户手动启动或开机自启。

#### Scenario: 会话启动自动启动服务
- **WHEN** 新的 Claude Code 会话启动
- **THEN** 通知服务自动启动并可用

#### Scenario: 全部会话结束自动停止
- **WHEN** 最后一个 Claude Code 会话结束
- **THEN** 通知服务自动停止,不残留后台进程

### Requirement: 降级通知
通知服务不可用时,系统 SHALL 仍以基础形式(无点击跳转)发出中断事件通知,不得静默丢失。

#### Scenario: 通知服务不可用时降级通知
- **WHEN** 通知服务未运行或不可用,且发生中断事件
- **THEN** 系统仍发出基础通知(不含点击跳转)

### Requirement: 通知失败不阻断会话
通知链路中的任何失败 SHALL NOT 中断或阻塞 Claude Code 会话的执行。

#### Scenario: 通知失败不阻断
- **WHEN** 通知脚本执行失败(如环境异常、依赖缺失)
- **THEN** Claude Code 会话继续正常运行,不受通知链路影响
