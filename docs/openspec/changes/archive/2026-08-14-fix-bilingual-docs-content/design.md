# 修复方案

以中文版为内容底稿,重写英文版正文。**单一方案,不做方案对比**(hotfix 精简)。

## 步骤

1. 打开 `CONTRIBUTING-zh.md` / `SECURITY-zh.md`,逐节将正文翻译为英文
2. 保留:
   - 文档结构与章节标题(章节标题翻译为英文,与中文版行数对应)
   - 代码块(`npm test` 等命令注释翻译为英文)
   - 语言切换链接(`English · [中文](CONTRIBUTING-zh.md)`,英文版中 "English" 不加链接,`[中文]` 指向 -zh.md)
   - `SECURITY.md` 的版本支持表格(✅ 保留)
3. 翻译完成后核对:
   - 中英行数差 ≤10(CI 双语镜像检查硬性要求)
   - 英文版正文无中文残留(语言切换链接除外)
4. 回归:运行 `npm test`(45 断言)确认不受影响(理论上无影响,防御性验证)

## 验收

- `CONTRIBUTING.md` / `SECURITY.md` 打开即是英文正文
- `node -e` 或 grep 检查两文件除语言切换链接外无汉字
- CI 双语镜像检查通过(行数差 ≤10)
